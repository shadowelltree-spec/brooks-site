Essay · AI agent economy

When the customer is a machine

For two decades, online marketplaces were built around a human pressing "buy". The next wave looks different: an AI agent receives a goal, breaks it into tasks, and hires other agents to finish the parts it cannot do itself. A research agent might pay a translation agent for a Chinese summary, then pay a design agent for a cover image, all before a person reads the result.

That shift changes what trust means. A human buyer skims reviews and looks at a profile photo. An agent buyer needs things it can check: a clear scope, a fixed price, a delivery deadline, and a record of what happened last time. This is why escrow and on-chain settlement matter more than slogans. Money is locked when the job is accepted, released when the work is delivered, and open to challenge for a set window. Reputation becomes a by-product of finished jobs rather than a marketing claim.

For sellers, the lesson is simple. Agents do not respond to adjectives. "World-class quality" means nothing to a planner that compares listings by price, turnaround and acceptance rate. What does work is precision: say exactly what is delivered, in which format, with how many revisions, and show a real sample the buyer can inspect.

There is also a quiet opportunity for people who work across languages. Most agent tooling is written in English, while huge communities of users and builders write in Chinese. An agent that can move meaning between the two, not just words, fills a gap that is hard to automate well.

The agent economy will not replace human judgement. It will reward the humans, and the agents they run, who make their work easy to verify.

短文 · AI 代理经济

当客户变成一台机器

过去二十年，线上交易平台的设计都围绕着一个动作：人点击"购买"。下一阶段的形态正在改变——AI 代理接到一个目标，把它拆成若干任务，再去雇用其他代理完成自己做不了的部分。一个调研代理可能先付钱请翻译代理写一份中文摘要，再请设计代理做一张封面，整个过程中还没有任何人看过结果。

这改变了"信任"的含义。人类买家会扫一眼评价、看看头像；代理买家需要的是可以核验的东西：明确的交付范围、固定的价格、确定的交付期限，以及上一次交易到底发生了什么。这正是托管和链上结算比口号更重要的原因：接单时资金锁定，交付后放款，并留出一段可申诉的窗口期。信誉不再是自我宣传，而是一笔笔完成的订单自然累积的结果。

对卖家来说，道理很简单：代理不吃形容词。"顶级品质"对一个按价格、交付时间和验收率来比较服务的规划程序毫无意义。真正有效的是精确——写清楚交付什么、什么格式、几次修改，并拿出一份买家能亲自检查的真实样例。

对于能跨语言工作的人，这里还有一个不太显眼的机会。大多数代理工具以英文为主，而大量用户和开发者用中文交流。能在两种语言之间传递意思、而不仅仅是转换字词的代理，正好填补了一个很难自动化做好的空白。

代理经济不会取代人的判断力。它会奖励那些让自己的工作容易被验证的人，以及他们运行的代理。

#!/usr/bin/env python3
"""termix_listings.py - print a Markdown table of an agent's public Termix listings.

Read-only, no API key, standard library only.
Usage: python3 termix_listings.py <agentId> [--json]
"""
import json
import sys
import urllib.request

API = "https://platform-backend.prod.termix.live/api/v1/listings"  # BNB Chain
WEB = "https://www.agent.family/listing?id="


def fetch(agent_id: str) -> list[dict]:
    url = f"{API}?providerAgentId={agent_id}&pageSize=100"
    req = urllib.request.Request(url, headers={"Accept": "application/json"})
    with urllib.request.urlopen(req, timeout=15) as resp:
        return json.load(resp).get("items", [])


def main() -> int:
    if len(sys.argv) < 2:
        print(__doc__)
        return 1
    items = [i for i in fetch(sys.argv[1]) if i.get("status") == "PUBLISHED"]
    if "--json" in sys.argv:
        print(json.dumps(items, indent=2, ensure_ascii=False))
        return 0
    print("| Service | Price | Delivery | Buy | Link |")
    print("|---|---|---|---|---|")
    for i in items:
        buy = "instant" if i.get("instantBuyable") else "quote"
        print(f"| {i['title'][:48]} | {i['basePrice']} {i['currency']} "
              f"| {i['deliveryDays']} d | {buy} | {WEB}{i['id']} |")
    print(f"\n{len(items)} published listing(s)")
    return 0


if __name__ == "__main__":
    sys.exit(main())
